# PayPal AI Hackathon 2026: Rules Summary

## Key dates (Pacific Time)
- **Submission deadline: Thu Nov 12, 2026, 12:00 pm PT** (hard cutoff, no edits after)
- Judging: Dec 1 to Dec 15, 2026
- Winners announced: around Dec 21, 2026

## What to build
- An app that integrates the **PayPal developer platform (sandbox)** plus **any AI tool/model**.
- PayPal integration must be **central** to the project (Venmo, Braintree, etc. also count).
- Must be new, or significantly updated since Oct 1, 2026 (explain what changed).
- Optional sponsor tools: AG Grid, APIMatic, Astropods, Bryntum, Channel3, Elastic, KERNEL, Postman, Render, Zapier.
- Sandbox access: https://developer.paypal.com/

## What to submit (on paypalaihackathon.devpost.com)
1. Text description of features and functionality.
2. **Public repo** (GitHub/GitLab/Bitbucket) with all source, assets and instructions.
3. **Open source license file**, visible in the repo's About section (e.g. MIT).
4. **Working demo**: either clear setup/run instructions in the README, or a hosted demo URL. Mockups don't count.
5. Test credentials / sandbox login details needed to run it (in the README).
6. **Demo video under 3 minutes**, public on YouTube, showing the app working. No copyrighted music or third-party trademarks without permission.
7. Everything in English.

## Judging
- Stage 1 (pass/fail): fits the theme and genuinely uses PayPal APIs/SDKs.
- Stage 2, equally weighted:
  1. Technological implementation (first tie-breaker)
  2. Design (complete product, not just a proof of concept)
  3. Potential impact (real problem, real audience)
  4. Innovation / idea
  5. Presentation (video shows it working end-to-end; clear problem/audience/why)

## Prizes
- Grand: $12k / $8k / $5k
- Honorable mentions ($5k each): Most Creative, Most Impactful, Best Demo Delivery, **Best Use of PayPal + AI**, **Best Use of Agentic Commerce**
- Sponsor: AG Grid ($5k / $2k / $1k x3), APIMatic ($1k x3 + subscription), Bryntum ($1k x3), Channel3 ($1.5k), Render (credits)
- Max per project: one Grand **or** one Honorable Mention, **plus** one Sponsor prize.

## Submission checklist
- [ ] Devpost registration done
- [ ] PayPal sandbox app + credentials created
- [ ] App working end-to-end in sandbox
- [ ] Public repo + LICENSE + README with setup and test credentials
- [ ] (Optional) hosted demo URL
- [ ] Demo video < 3 min on YouTube (public)
- [ ] Devpost form submitted before Nov 12, 12:00 pm PT
